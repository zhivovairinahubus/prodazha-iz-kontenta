# Прототип «Продажа из контента» — статический сайт (22.11.2026)

Кликабельный прототип «Продажа из контента» — Команда 1, VK Case Champ 2026. Открыть: https://zhivovairinahubus.github.io/prodazha-iz-kontenta/

Один файл `index.html`: стили, SVG, данные курсов и логика внутри, без внешних CDN, шрифтов и сборщиков. Hash-роутинг, работает на GitHub Pages и при открытии файла с диска. Мобильный вид (на телефоне во весь экран, на компьютере — в рамке 390×844).

## Маршруты
| Адрес | Экран |
|---|---|
| `#/` | Главная: гипотеза команды (4 барьера → решения) и 5 карточек |
| `#/launch` | Пр1. Мастер «Запуск продаж»: товары → доставка → оплата → готово |
| `#/product` → `#/done` | Пр2 + Пр3. Карточка «Купить в VK», оформление с VK Pay и гарантией, заказ оплачен |
| `#/promote` | П3. Клип → «Продвигать товар»: 3 шага, цель, бюджет-слайдер с прогнозом заказов, запуск |
| `#/stats` | К4. Статистика «публикация → заказ» |
| `#/academy` | VK Академия: каталог из 5 курсов с обложками, фильтр «Видео / Тексты / Практика» |
| `#/course/<id>` | Страница курса: описание, «Чему научитесь», список уроков (видео-превью, текст, практика) |
| `#/course/<id>/<n>` | Урок: видео-превью с play и таймингом / текст / практика + тест 2–3 вопроса |
| `#/course/<id>/final` → `/cert` | Итоговый тест и сертификат с кнопкой «Применить» в нужный экран |

Курсы (`id`): `ads` «Реклама товара за 3 шага» (видео), `delivery` «Как настроить доставку и оплату» (практика), `card` «Карточка товара, которая продаёт» (текст), `stats` «Статистика: какая публикация принесла заказ» (видео), `reviews` «Работа с отзывами и повторными продажами» (текст).

## Кнопка «?»
Есть на каждом экране сценариев (в шапке) и у ключевых полей: вес посылки, оплата, гарантия сделки, отзывы, цель, бюджет. Открывает шторку «Пройдите обучение»: обложка, название и описание курса к этому экрану, кнопка «Начать обучение» ведёт в каталог, где этот курс стоит первым с пометкой «Рекомендуем для этого экрана».

Следующий урок открывается после верных ответов на все вопросы. Итоговый тест засчитывается при ошибке не больше чем в одном вопросе. Прогресс курсов сохраняется в браузере (localStorage).

## Исходники и проверка
`src/style.css`, `src/courses.js`, `src/app.js`, `src/candle.svg` → `python3 src/build.py` собирает `index.html`. Проверено Playwright: пройдены все маршруты, полный курс до сертификата, практики, фильтр, мобильный и десктопный вид, ошибок в консоли нет.

Цифры о текущем состоянии на главной — датасет VK Case Champ 2026 (реестр v3). Сообщество «Тёплый воск», цены, прогнозы, статистика и курсы — пример интерфейса. Деньги нигде не списываются.
